Android ARM64 tools (Android 10 / API 29 and newer)

Extract the archive. The executable files are in bin/.
Use a shell-owned executable directory, for example /data/local/tmp/tools.
No root is required for normal file processing or network requests.

Example from your computer with adb installed:
  adb shell mkdir -p /data/local/tmp/tools
  adb push bin/. /data/local/tmp/tools/
  adb shell chmod 755 /data/local/tmp/tools/curl
  adb shell /data/local/tmp/tools/curl --version
  adb shell /data/local/tmp/tools/curl -I https://example.com

curl includes OpenSSL, nghttp2 (HTTP/2), zlib (gzip) and an embedded
Mozilla CA bundle. HTTPS certificate verification is enabled by default.
Use --cacert /path/to/custom-ca.pem for a private CA, or set CURL_CA_BUNDLE.
The embedded CA bundle is a build-time snapshot; rebuild it when updating
trusted certificates. HTTP/3, SSH/SFTP and Brotli/Zstd are not included.

jq includes the Oniguruma regular expression engine when selected.

These binaries are built for Android ARM64, not desktop Linux ARM64.
File access and network permissions are those of the shell/app running them.
Android's shared storage (for example /sdcard) normally cannot execute files.

Verify package contents after extraction:
  sha256sum -c SHA256SUMS

The licenses/ directory contains upstream notices for the distributed code.
sources.json records upstream versions, URLs and archive checksums.
